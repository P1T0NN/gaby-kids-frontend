# Product

## Register

product

## Users

Developers using this repository as a reusable foundation for future Svelte applications.

## Product Purpose

Provide a dependable universal template whose product-specific design can change without fighting the underlying application shell and components.

## Brand Personality

Neutral, adaptable, dependable.

## Anti-references

Avoid opinionated branding, decorative effects, and project-specific styling in shared template components.

## Design Principles

- Keep shared UI adaptable to different future products.
- Prefer native, familiar interaction patterns.
- Make responsive behavior useful rather than merely compressed.
- Preserve clear hierarchy with minimal visual assumptions.

## Accessibility & Inclusion

Target WCAG 2.2 AA. Support keyboard and screen-reader navigation, reduced-motion preferences, native semantics, and adequate touch targets and contrast.
